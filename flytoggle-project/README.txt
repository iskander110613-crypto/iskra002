FlyToggle — как собрать jar одним из двух способов.

СПОСОБ 1 — через GitHub (ничего устанавливать не нужно):
1. Зарегистрируйтесь на github.com (если аккаунта ещё нет).
2. Создайте новый репозиторий (Public), загрузите в него все файлы из этого архива
   (кнопка "uploading an existing file" на странице репозитория).
3. Откройте вкладку Actions — сборка запустится сама. Подождите пару минут.
4. В завершившейся сборке (зелёная галочка) откройте её, в низу раздел Artifacts
   скачайте flytoggle-jar. Внутри архива будет flytoggle-1.0.0.jar.
5. Положите jar вместе с Fabric API в папку mods.

СПОСОБ 2 — на своём компьютере:
1. Установите JDK 25 (например, Temurin).
2. Распакуйте архив, в его папке выполните: gradle build
   (нужен установленный Gradle 9.x; либо выполните "gradle wrapper", затем "./gradlew build").
3. Готовый jar будет в build/libs/flytoggle-1.0.0.jar.

Важно: сборка качает Minecraft и Fabric из интернета, так что сеть нужна.
Играете по сети с друзьями — мод должен стоять и на сервере.
